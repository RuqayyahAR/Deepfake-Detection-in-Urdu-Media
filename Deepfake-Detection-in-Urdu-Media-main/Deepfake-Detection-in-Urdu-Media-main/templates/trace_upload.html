Source Tracing: Compare Against a Reference

Source tracing answers: Is this video the same as a known reference, and which parts were altered?

Upload two videos:

  • Suspect video: the video you want to check
  • Reference video: the known original to compare against

The app extracts per-frame video fingerprints and per-second audio fingerprints, aligns them, and labels each second as:

  • MATCH - both video and audio agree with the reference
  • VIDEO_ALTERED - video differs, audio matches
  • AUDIO_ALTERED - audio differs, video matches
  • BOTH_ALTERED - both differ


How it works: The app computes a 64-bit perceptual hash for every 0.5s video frame and a 16-bit spectral-shape hash for every 0.25s audio window. It slides the suspect over the reference to find the best offset, then labels each second based on whether video and/or audio match the reference within threshold (0.25 normalised Hamming distance).

⚠ Limitation

Source tracing tells you whether a video matches a reference and where it differs. It does not tell you whether a video is a deepfake. Use this alongside the deepfake detection result for a complete investigation.
